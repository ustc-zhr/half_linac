# HALF 发射度优化：InfoBAX 标签页

正式入口：主发射度应用 → **Emittance Optimization** → **InfoBAX**。
“Conventional · RCDS / BO / CBO”和“InfoBAX”共用磁铁选择、电流范围、目标平面、时限、螺线管稳定时间和底部操作区。
两页分别保留算法参数和运行结果；一次只能执行一个会话。

## 测量设置与查询点

InfoBAX 直接冻结主窗口当前的 Gaussian、Projection RMS 或 Robust Projection RMS 方法，以及 ROI、背景、拟合强度阈值、能量、相机几何、采样帧数、四极铁稳定时间和帧间隔。
没有单独的一套 InfoBAX 相机配置或默认 RMS 覆盖，也不自动计算另一种宽度作为模型输入。
每点至少 **3 帧**，帧数不足时先在主窗口调整；不会静默覆盖主窗口设置。

K1 范围和点数也来自主窗口：

- Grid：使用扫描起止值和点数。
- Adaptive / Adaptive Quality：使用允许搜索上下限和最大点数，构成 InfoBAX 的固定候选网格。
- 相对范围通过既有限值规则转换为绝对 K1，结合机器限值冻结。主窗口的扫描模式不被修改。

基线和最终复核按完整网格扫描。后续主动测量点由 InfoBAX 在“电流候选 × K1 候选”中选择。

- `Current candidates` 设置候选工作点总数，界面支持 2 到 99，默认 5。只选一台螺线管时用等距电流网格。多选时在各自范围内用固定种子的拉丁超立方抽样生成电流组合。初始电流组也包含在候选中，候选须满足设备读回间距要求。
- `Initial K1 points per end` 设置两组相距最远的候选各自的初始化 K1 点数，默认 3。M0 至少 1 点，`transport_moments` 至少 3 点，上限为 K1 网格点数。多台螺线管按各自电流范围归一化后计算距离。每组先按传输矩阵的 QR 主元顺序选至多 3 个 K1 点，超过 3 点时按 K1 间距补点。重复点复用基线数据。
- `Active query limit` 设置初始化后的单点测量预算，默认 3 次。实际查询次数还受剩余未测候选点和会话时限限制。

默认后验为 `transport_moments`。也可选 **Direct variance GP (M0)**，直接对束斑方差建模。该模型在归档中标记为 `M0`，也是数值核心的默认模型。

在 `Variables` 表里勾选扫描段上游的螺线管，为每台填写电流上下限。各台电源组成同一优化工作点，统一核对到位及恢复。

## ICT1 电荷约束

`ICT1 constraint` 默认关闭。打开后，`Minimum ICT1 charge retained` 默认为 **95%**，下限为基线整扫的 ICT1 截尾均值乘以保留率。基线和独立复核各做一次全扫。ICT1 以螺线管电流组合为输入单独建模，主动查询按“电荷达标时发射度最低的候选”的信息增益排序。界面显示各候选的 `P(best)`、ICT1 达标概率，以及 `INVALID` 和 `NO_FEASIBLE`。

设备稳定后，程序在首帧前读取 ICT1。采样次数使用主窗口的每点帧数，间隔至少为机器配置中的 CT 刷新间隔。仅接受当前稳定窗内有新鲜源时间戳的读数。使用 10% 截尾均值，至少需要 3 个有效样本和 80% 的有效覆盖率。搜索中低于下限的有效读数仍用于学习。完整复核电荷达标、且目标发射度降低后才允许 `Apply Best`。应用到位再查一次 ICT1，电荷不达标或缺测时恢复初值。

约束运行保存 v3 归档，`ict1_windows/` 包含独立的稳定窗读数和设备读回。下方命令在同一数值环境中核对 ICT1 判定、EIG 排序和推荐。

```bash
python3 scripts/replay_emit_infobax.py <运行目录>
```

现场短测先核对 ICT1 的时间戳刷新与基线稳定性，再用小候选池运行 A0 基线、主动查询和 B 独立复核。恢复初值后按同一网格和测量口径复扫 A1，用 A0/A1 的差异评估漂移。

## 共用的测量与结果口径

普通扫描、BO 和 InfoBAX 调用同一采集服务，包含移四极铁、稳定等待、采图、背景/ROI/阈值处理和逐帧束宽计算。
普通扫描原有自适应、重试、选点和拟合行为保留。

InfoBAX 基线和复核通过与 BO 共用的测量桥调用现有 `scanThread`，使用其传输矩阵、最小二乘重建、归一化和归档结果。
不再维护原型中独立的完整扫描加权拟合。相同设置与图像的束宽、重建结果采用现有应用口径。

模型观测取所选平面逐帧 `σ²` 的均值，标准误取这些值的样本标准差除以帧数平方根。
零/无效标准误、无效图像或目标平面质量不合格会停止并还原，不补噪声、不自动放宽判据。
实测发射度以完整扫描的 `exn_raw` 为准，后验页面展示最佳工作点和 INVALID 的概率。

采样沿用现有 **定时采样**，不要求 `frame_id`。界面与归档标记 `timed_unverified`，表示未验证各次读取一定来自独立新帧；标准误是重复测量统计，不代表已校准的独立帧噪声。
稳定时间与帧间隔由操作员按相机曝光、刷新和传输延迟设置。VM 粒子计数噪声系数不用于真实相机 ADU。

## 启动、停止与恢复

1. 开始时在 worker 持有发射度控制锁后读取设备、准备模型并保存初始状态。打开优化窗口或切换标签页不启动测量。
2. 点击 Start 后，程序自动执行基线扫描、初始化、主动查询和最终复核。界面显示正在测量的电流和 K1 或剩余网格点数。
3. 单点查询不逐点恢复全部磁铁。
4. 完整扫描保持原有扫描四极铁还原契约。会话暂停、停止、超时、异常和完成时尝试还原全局初始状态。
5. 取消扫描后先等待其退出与四极铁还原，再进行外层还原。一个供电失败不会跳过其他设备。
6. 只有完整复核物理有效、目标发射度低于基线时，才可确认“Apply Best”。应用会写入复核时的整组螺线管电流。

运行中锁定标签切换和公共设置；底部停止/还原操作始终可见。
还原失败保持主窗口锁定、禁用应用结果，使用 Restore Initial 恢复成功后解除锁定。
已完成的基线/复核点逐点持久化；继续暂停会话仅补测未完成点，设置或模型漂移拒绝恢复。

## 归档与兼容

运行目录使用现有机器/后端应用运行目录下的 `infobax_<时间>_<ID>`。
关闭 ICT1 约束时，`infobax_workflow.json` 使用 v2，绑定共享测量快照、方法、模型、K1 来源与列表、设备映射、初始化、逐点记录和完整扫描结果。
基线和复核各自拥有私有 `latest/`、`runs/` 和原始帧目录，不覆盖普通扫描的 latest。

优化窗口的 Open Run 在 InfoBAX 页识别相应归档。旧 v1 原型归档仅只读查看，不构造可执行机器会话，不直接恢复或应用；可清除当前归档开始新运行。
v2 和 v3 暂停会话须匹配归档的测量及优化设置后继续。进程中断或未完成的人工设备操作需先恢复初始状态。
归档恢复只核对目标设备映射及限值并还原初始磁铁，不要求相机或测量模型当前可用；此恢复句柄不能执行查询或应用推荐。

原严格 frame-ID 相机接口仅保留为共享服务的兼容导出，用于旧测试和隔离检查，正式框架路径不依赖它。

## 启动、离线与隔离验证

从框架主窗口进入，或通过兼容启动脚本打开同一页面：

```bash
bash scripts/run_emit_infobax.sh --backend real
```

脚本默认仍为 Fake 调试入口；无界面模式只允许模拟操作：

```bash
bash scripts/run_emit_infobax.sh --headless --approve-fake --quick --run-root /tmp/emit-infobax-smoke
```

验证命令：

```bash
source scripts/setup.sh
python3 -m unittest discover -s tests -p 'test_emit_measurement_service.py' -q
python3 -m unittest discover -s tests -p 'test_*infobax*.py' -q
python3 -m unittest discover -s tests -p 'test_emit_optimization*.py' -q
python3 scripts/check_emit_infobax_standalone_ioc.py --output /tmp/emit-infobax-ioc --sampling timed
bash scripts/check.sh
```

隔离 IOC 使用随机测试前缀和私有 loopback 通道，默认不提供 frame_id，检查共享定时采样、16 点/80 帧及磁铁还原；可用 `--sampling verified` 检查旧严格帧策略。
GUI 集成测试使用实际扫描线程和模拟 PV，验证完整扫描、暂停续测、无帧标识启动、只读历史和故障恢复。

现场核对设备范围、能量、背景/ROI、采样时序与还原。
