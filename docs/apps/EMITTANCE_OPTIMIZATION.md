# HALF 发射度优化

在 emittance 窗口顶部点击“发射度优化”。使用主界面当前选择的扫描四极铁、测量屏及最终最小二乘重构，支持多路螺线管电流联合优化。目标是所选平面的**归一化投影发射度**，不是四维或本征发射度。优化面板保持英文。

## 操作

1. 在变量表中勾选螺线管（默认只选一路），用 `Read Currents` 读取所选设置值，为每一路填写独立的绝对电流上下限（A）。范围必须包含运行启动时重新记录的设置值，且不能超过机器配置限制。未选中的元件不参与写入。
2. 选择 `RCDS` 或 `Bayesian Optimization (BO)`，选择最小化 X 或 Y，并填写另一平面允许的发射度上限（mm·mrad）。
3. 在主界面核对当前测量屏的能量，优化面板只读显示该值；核对测量预算，默认预算为 20 次完整测量、120 分钟。界面显示所选变量数及扣除四次基线/复测后的搜索预算；变量增加通常需要增加完整测量次数和时间预算。
4. 点击开始。先测两次基线，再调用所选算法搜索，并为最佳候选点预留两次复测。
5. 运行结束恢复整组初值。只有两次复测均合格、满足约束且目标均值优于基线，才启用 `Apply Best`，应用最佳候选点的整组电流；这项操作不会自动进行。更改面板设置后旧最佳值失效，`Restore Initial` 仍使用原运行记录的整组初值。

变量列表从机器配置的 `solenoid` 元件及其电流通道动态生成。所选螺线管必须位于当前扫描四极铁上游，启动前会校验机器配置中的元件顺序；扫描四极铁不作为优化变量；其他四极铁和 RF 暂不开放。底层使用有序变量向量，每个变量具有独立范围。

`RCDS` 保持默认，适合从当前工作点开始的局部、无导数搜索。`BO` 首先测量当前工作点，使用固定随机种子的 Latin hypercube 补足初始样本，再以 Matérn 5/2 高斯过程和 Expected Improvement 顺序选择测量点。BO 基于项目已有的 scikit-learn，不依赖可选的 PyTorch/BoTorch 环境。两种算法使用相同的总测量预算、停止检查、另一平面惩罚、最佳点复测和恢复流程；选择及 BO 模型配置写入运行档案。

算法下方只显示当前算法的必要参数：RCDS 的 `Initial step fraction` 默认 0.2，按每路变量范围计算初始步长；BO 的 `Initial samples` 默认 `max(3, 2 × 变量数 + 1)`，包含当前工作点且不得超过 `Max. scans - 4`，`Exploration` 默认 0.01。BO 的 `Random seed` 默认 0，位于 `Advanced` 折叠项中，用于复现初始设计和候选点序列。用户手动修改初始样本数后，变量选择变化不再覆盖该值。所有实际生效参数写入 `optimization.json`；修改任一算法参数会使旧的已验证最佳点失效。

扫描四极铁、测量屏、能量、扫描范围、采样、自适应参数、ROI、背景和束斑算法直接继承主窗口当前设置。优化面板显示 `Measurement: 四极铁 → 测量屏`，不再另设测量位置或能量。启动时冻结参数与背景副本，按当前测量段选择模型并保存快照；运行中锁定主窗口相关控件。优化不会切换普通测量的预设，也不会覆盖其 `latest` 数据。

优化直接使用主窗口当前的扫描 mode。`Grid`、`Adaptive` 和 `Adaptive Quality` 均可使用；`Adaptive Quality` 会额外要求各平面通过其质量验证，其他 mode 使用普通有效重构结果。切换测量段后，请先确认主界面能量适用于新屏；使用预设会沿用普通测量原有的能量默认值。

螺线管稳定等待由优化面板的 `Solenoid settle time (s)` 独立设置，默认 2 秒，支持 0–3600 秒（0 表示不额外等待，到位核验仍保留）。整组到位后等待，再次核验后开始测量；不继承或修改主界面扫描四极铁的等待时间。电流到位默认容差 0.01 A、超时 10 秒。上述参数通过 `OptimizationConfig` 随运行归档。当前扫描四极铁恢复同时核验 K1 和实际电流读回。现场需核对这些设置是否适用。

## 停止、失败和数据

- 每次扫描线程退出并完成 当前扫描四极铁恢复后，优化才接收其终态结果。中间拟合结果不参与搜索。
- 两个平面都必须通过质量检查，使用未取整的归一化发射度。目标标量为 `ε/(ε+ε₀)`，另一平面超限的有效测量使用惩罚值 2。
- 无效测量最多完整重测一次；重测计入总预算。写入失败、到位超时、扫描执行错误或恢复失败立即结束搜索。
- 首次写入前记录所有所选元件的初值并检查整组范围和连接；每次候选点在整组电流到位并稳定后才开始测量。
- 点击停止或关闭运行中的窗口，会先停止扫描并恢复当前扫描四极铁，再恢复所有所选螺线管。恢复动作不被停止请求打断；一路恢复失败仍继续尝试其余电源，并逐项归档恢复结果。
- 恢复失败保持故障信息与操作锁定；排除设备问题后可点击“恢复初值”重试。未完成恢复不能正常关闭窗口。
- 同一窗口内的冲突控制在运行期间锁定，结果和页签仍可查看。此功能不提供跨进程设备占用锁。

档案位于 `src/apps/emit_measure/runtime/half/real/runs/optimization_<时间>_<标识>/`。`optimization.json` 使用 `emit_optimization_v2` 格式，记录变量顺序、各元件初值、候选电流向量及名称映射、基线、测量质量、约束、复测与逐项恢复结果；各次扫描使用独立子目录。启用背景时另存冻结的 `background.npy`。普通测量的 `latest` 不会被覆盖。

## 验证范围

本版没有新增 PV、IOC 或 VM 通道。HALF VM 缺少螺线管电流映射，面板在 VM 下不允许启动，也不会自动切换实机。

开发验证使用模拟电源、模拟测量、mock EPICS 和 Qt 离屏测试；未连接实机。可运行：

```sh
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -p 'test_emit*.py'
bash scripts/check.sh
```

若本机 Qt 插件不在自动搜索路径，需设置 `QT_QPA_PLATFORM_PLUGIN_PATH` 指向当前 Python 环境的 Qt `platforms` 目录。

首次现场验收应依次确认读回与恢复、所选测量段的基线重复性，再进行小范围优化。复测平均值下降不等同于统计显著改善；界面和档案保留基线及复测结果供判断。
