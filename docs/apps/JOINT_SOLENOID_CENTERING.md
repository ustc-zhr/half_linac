# 联立螺线管 Centering

现有单管功能保留。打开 Solenoid Centering，在标题栏选择 **联立 Centering**。
首版用于 HALF 现场试验；本地验证使用注入的模拟 IO，不改变 VM/实机写入策略。
算法模块 `src/apps/solenoid_centering/joint.py` 不包含 HALF 设备名。

## 操作

1. 选择三管组（SM01、SL01-1、SL01-2）或完整五管组（再加 SS01、SS02）。
2. 确认表中每管调制半幅、校正子探测幅度、每轮/累计调整上限、响应容差与迭代次数。
3. 点击“预检 / 估时”，检查参与通道、计划电流范围和预计时间。
4. 点击“开始联立扫描”。结束、停止或异常时恢复本次初始设置，并验证读回。
5. 检查每个螺线管的初始/最终响应 RMS 和校正电流；通过验收后可“应用推荐值”。
   应用前再次检查原始状态。应用后保留“恢复初始值”操作。

HALF 首版默认 SM/SL 调制 ±0.5 A，SS 调制 ±0.2 A，校正子探测 ±0.2 A，
每轮最多 0.25 A，累计偏离初始值最多 0.5 A，最多两轮。响应容差暂为 0.01 mm。
这些是可编辑的试验起点，尚未用 HALF 实测确认信噪比或合适幅度。

三管组使用 XC02/YC02、SM01-DX/DY、SL01-DX/DY 六个通道。
五管组另加 XC00/YC00、XC01/YC01，共十个通道。
SS01/SS02/SM01 使用 BPM01 和 BPM02；SL01-1/SL01-2 使用 BPM02。
上述观测关系依据当前束线描述配置，现场需确认；不根据 machine.json 的 order 推断纵向位置。
三管模式检查其他已配置前段磁铁的电流是否变化，但不扫描 SS01/SS02；
因此三管验收不能代替 SS01/SS02 的单独回测。

## 测量与计算

- 初始五点扫描记录各管响应曲线，其他螺线管保持原工作点。
- 两点调制取 `(BPM(+ΔI) - BPM(-ΔI)) / 2`；每管的所有 BPM X/Y 一起组成残差。
  每管按观测分量数归一化，避免仅因多一个 BPM 而增加权重。
- 各校正子正负扰动，测全组两点响应，建立响应矩阵。再次测量基准，然后复用矩阵迭代。
- 在探测步长归一化的坐标中采用截断 SVD 与阻尼；全局缩放修正步以满足每轮及累计限幅。
  矩阵秩与奇异值写入结果，弱方向不强行求逆。
- 每个候选都实际回测。总响应至少改善 5%，且任何一管不能恶化超过 20%
  （低于绝对响应容差的变化允许），才接受该步。低于响应容差的基准不提供推荐。
- 最终五点扫描使用整条曲线去均值后的 RMS 验收，而非仅看局部斜率。
  不通过时不提供应用。首版候选失败就停止，不自动重建矩阵。

首版不跳过任何组内交叉响应组合；也不同时激励多个螺线管。
首次辨识较慢，但后续迭代不再逐个扰动校正子。预检显示等待时间估算，额外通信、
读回确认和恢复会增加实际耗时。默认采样继承各单管 preset。
静态 BPM 零偏由差分消除；BPM 噪声、束流漂移和磁滞仍会影响结果。
采样原始值保留供复查，首版不自动拟合噪声权重或机械磁轴位置/角度。

## 通用配置与结果

在机器的 `apps/solenoid_centering.json` 增加可选 `joint_centering`：

```json
{
  "joint_centering": {
    "defaults": {"probe_a": 0.2, "max_iterations": 2},
    "groups": [{
      "id": "example",
      "display_name": "Example group",
      "targets": [{
        "preset": "existing_single_solenoid_preset",
        "bpms": ["downstream_bpm"],
        "modulation_a": 0.5
      }]
    }]
  }
}
```

校正通道从所选单管 preset 的 hcorr/vcorr 去重得到，不复制机器可选设备目录。
组可以通过 `options` 覆盖 `JointPlan` 中的算法参数；首版只支持有电流限幅与读回的 A 通道。
未配置联立方案的机器不显示入口。新机器只需配置设备引用、观测关系和扫描参数。
PV 命名、IOC DB 和 VM/IOC 同步未改动。

联立记录单独存于 `runtime/<machine>/<backend>/joint/{latest,scans}`，包含配置、
初始电流、原始 BPM 样本、响应矩阵、奇异值、每轮验收、推荐值、异常与恢复状态。
不覆盖单管的 latest result。扫描结果代表工作点附近的联合最小响应，
不保证已经唯一测得每根磁轴，也不保证所有磁铁能同时严格居中。
