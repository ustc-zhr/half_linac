# IRFEL FIR 色散 BPM 前馈预测初测

## 结论

现有数据证明了同一运行内的下一控制窗预测信号，但还不支持部署一个跨日固定的 NN 前馈模型。

- 在 2026-11-01 单次数据内以前 70% 训练、后 30% 测试，最佳 Ridge 将下一 10 s 窗 BPM04.x 的 RMSE 从持久性基线的 0.10395 mm 降到 0.08646 mm，MSE 技能为 30.8%。
- 小型 MLP 的最佳同日结果为 0.09194 mm，技能为 21.8%，没有超过 Ridge。
- 使用 2026-10-23/24 训练、2026-11-01 测试时，最佳模型技能只有 3.4%；MLP 为负技能。固定模型存在明显跨日分布漂移。
- 最佳同日模型主要依赖 BPM02 的短期变化，其次才是 BPM04 历史。这说明可预测成分中有较强的入射轨道传播，不能直接当作能量扰动送给高压执行器。

因此当前适合进入 `shadow` 验证，并先以 Ridge 作为必须超过的基线。NN 暂不进入自动写入链路。

三次运行均为 FIR 20 MeV，备注为空调关闭。11 月 1 日的均值和动态范围相对 10 月已有明显变化。

当前 FIR 配置使用 `a = 0, b = 0`，所以本次目标实际是 BPM04.x：

```text
q = x04
```

它还不是完成上游轨道扣除后的 `q_energy = x04 - a*x02 - b*x03`。数据中的高压读回标准差只有约 0.0013–0.0015 kV，也没有受控执行器激励，因此本次测试不能辨识高压响应、控制延迟或闭环改善量。

## 测试方法

1. 每 50 个 0.2 s 样本取中位数，与当前 10 s 控制周期一致。
2. 使用 `BPM04.s > 1000` 作为离线束流门控。
3. 预测目标为下一控制窗的开放环扰动增量：

   ```text
   d[k+1] = q[k+1] - q[k]
   q_hat[k+1] = q[k] + d_hat[k+1]
   ```

4. 使用最近 10、20、30、60、120、300 s 的因果历史。相位变化按圆周角处理。
5. 跨日测试只使用三次采集共有的通道，不用 11 月新增而 10 月缺失的通道。
6. 比较 Ridge、直方图梯度提升和两层 MLP；基线为 `q_hat[k+1] = q[k]`。
7. 另与简单趋势外推比较。最近 120 s 平均变化率的技能只有 6.3%，低于最佳 Ridge 的 30.8%。

这里的技能定义为：

```text
skill = 1 - MSE(model) / MSE(persistence)
```

## 与 PI 联合的建议形式

模型应预测执行器尚未作用时的外部扰动增量，而不是直接输出高压设定值。在线有控制动作后，训练标签应改为：

```text
d_external[k+1] = q[k+1] - q[k] - R * delta_u_applied[k]
```

其中 `R = dq/du` 是实测高压响应。运行时：

```text
delta_u_ff = -d_hat_external[k+1] / R
delta_u_cmd = saturate(delta_u_ff + delta_u_pi)
```

PI 继续根据当前实测 `q` 与参考值的误差工作。饱和、session limit、写后校验、束流/RF/HV 门禁和控制锁均作用于合成后的最终命令。PI 的 anti-windup 必须跟踪实际执行的总命令，避免积分器与前馈互相追赶。预测器缺通道、超出训练分布、模型版本不匹配或推理超时后，`delta_u_ff` 直接置零，保留现有 PI。

按当前配置 `R = 0.01 mm/kV`、单步上限 `0.02 kV` 推算，单次最大可补偿量仅 `0.0002 mm`，远小于数据中约 `0.05–0.13 mm` 的下一窗变化。这个响应值和步长组合需要通过受控扫描重新确认，否则 NN 和 PI 都会长期处于限幅状态。

## 实现边界

训练和模型选择适合放在离线脚本或训练模块中；通过验证的只读推理适合接入现有 `energy_feedback`，复用现有测量、门禁、执行器、日志和控制锁。无需另做一个能够直接写高压的应用。

模型文件至少应绑定：通道列表及顺序、10 s 窗定义、缺失值规则、相位变换、`a/b/R` 标定版本、训练运行列表、时间外测试指标、软件版本和模型哈希。任一绑定项变化时退回 PI-only。

建议按以下顺序继续：

1. 用独立上游轨道小扫描标定 `a/b`，把目标换为 `q_energy`。
2. 用安全的小高压阶跃或 PRBS 标定 `R`、响应延迟和线性范围。
3. 连续采集至少 5–10 个不同日期的同工作点数据，并记录实际控制命令。
4. 先上线 Ridge shadow，同时记录 NN shadow；用逐日向前留出评估，而不是随机切分。
5. 只有 NN 在多个未见日期稳定超过 Ridge 和持久性基线，并通过饱和命令回放后，才开放限幅前馈；PI 始终保留。
