# VM Workbench 第二版：磁铁调参与基线比较

## 目标与开发隔离

同时支持四极铁光学调节和校正铁轨道调节，完成“修改设定 → 计算反馈 → 比较基线 → 恢复磁铁”的闭环。覆盖 HALF、IRFEL，保持全英文界面及明暗主题。

基于第一版提交 `5ad8303` 新建 `feat/vm-workbench-v2`，使用独立 worktree `/home/zhanghaoran/gitproj/half_linac_vm_workbench_v2`。保留当前 `main` 工作目录及其中的运行产物；第二版开发、启动和测试均使用独立目录。

## 元件编辑与写入路径

- 在 `Devices` 参数区增加四极铁 `K1`、水平／垂直校正铁 `Kick` 编辑器。支持精确输入、自定义步长、加减按钮、`Apply` 和 `Discard`；步进只修改待应用值。
- 四极铁显示单位 `m⁻²`，校正铁显示 `mrad`，后者写入前转换为通道使用的 `rad`。初始步长分别为 `0.01 m⁻²`、`0.01 mrad`，仅作为编辑步长。
- 展示当前 PV 设定、模型值和待应用值。四极铁选择默认切到 `Twiss`，校正铁切到 `Orbit`；再次刷新数据不改变用户选择，诊断屏幕始终独立。
- 可编辑对象从当前 usedline 与 machine profile 中的 `quad`、`corr` 类型及虚拟写通道交集推导。其余元件只读；重复元件按出现位置选择，但共享同一个模型参数与 PV，界面明确提示影响全部出现位置。
- 所有磁铁写入固定走虚拟 softIOC，由现有 `pv_server` 回调更新 JSON。复用 `resolve_write_target(..., mode="vm")` 解析 PV、单位及限值，不硬编码 PV、不直接修改磁铁 JSON、不回退到真实通道。
- 校验有限数值和已配置限值；未配置限值时明确显示 `Limits not configured`，不虚构范围。断连或通道映射缺失时禁用 `Apply`。
- 外部应用更新同一 PV 时同步显示；若存在本地草稿，则显示 `External Change` 并阻止应用，用户点击 `Discard` 重新载入当前值后再编辑。提交前再次读取设定，检查是否发生变化。

## 写入确认与结果版本

- 新增 VM 专用异步调参控制器，负责通道订阅、单位转换、提交前检查、写入和状态跟踪；Qt 主线程只接收信号并刷新界面。
- 操作状态依次为 `Writing PV`、`Waiting for Model`、`Calculating`、`Applied`。PV 写入成功不等于计算完成；诊断发布失败继续作为独立警告。
- 先确认 PV 设定和 JSON 目标字段一致，再等待对应完整输入版本的成功结果。优先使用已有通道容差；缺省采用内部单位下 `rtol=1e-9、atol=1e-12`。
- PV 写入等待上限 2 秒，模型同步等待上限 5 秒；计算阶段持续显示真实运行状态与耗时，不使用上述超时终止 Elegant。失败或超时保留实际状态及原因，不自动重复写入。
- 若等待期间输入被外部修改，标记 `Superseded`，不把后续其他版本的结果当成本次操作完成。用户可重新读取当前状态继续操作。
- 扩展第一版结果快照，保存本轮冻结的原始输入；捕获位置在 GUI 专用 sigma 输出配置注入之前。这样基线参数与结果来自同一轮计算，不从实时 JSON 拼接历史结果。
- 不复用当前仅允许真实后端的 `control_transaction` 恢复执行器，也不改变它的真实机器约束。

## 会话基线与磁铁恢复

- 增加 `Set Baseline`、`Show Baseline`、`Restore Magnets`。第二版仅保留一个会话内基线，不提供文件保存／载入。
- `Set Baseline` 仅接受当前会话、当前输入版本的成功结果，并确认支持的磁铁 PV 与该结果的输入一致。保存完整输入、结果及当前线路中的可写磁铁设定。
- 当前曲线保持实线，基线使用同色虚线。独立诊断区显示同一 WATCH 的当前值、基线值与差值：`Cx`、`Cy`、`σx`、`σy`；没有有效数据的指标显示 `Unavailable`。
- 基线兼容性通过输入比较判断：仅忽略本版可恢复磁铁的 `K1`／`KICK` 字段。线路、束源、随机种子、误差、其他模型参数或机器配置改变后，标记 `Baseline incompatible`，关闭叠加与恢复，保留基线供用户明确替换。
- `Restore Magnets` 展示发生变化的磁铁及当前值、目标值；用户确认后，只通过虚拟 PV 恢复这些磁铁，不恢复束源、线路或误差。
- 恢复前统一检查连接、目标限值和基线兼容性；按线路顺序逐项写入并确认，同一 PV 去重。写入过程中锁定本窗口的其他配置操作。
- 恢复不是跨 PV 原子事务。遇到失败、取消或外部冲突时停止后续写入，列出已完成、失败和未执行项，不自动回滚覆盖其他应用的设置。最后一项同步完成后，等待最终输入版本的计算成功，才显示恢复完成。

## 验证与验收

- 离线测试：两种机器的通道解析、单位换算、限值校验、重复元件去重、断连和外部修改冲突。
- 模拟异步链路：PV 成功但 JSON 未同步、计算失败、操作被新输入取代、发布部分失败，以及恢复中途失败／取消。
- 基线测试：输入与结果绑定、曲线叠加、诊断差值、缺失数据，以及线路／束源／误差改变后的失效处理。
- 离屏测试：英文文案、两种主题、1366×768 布局、两类编辑器、草稿切换处理和屏幕独立选择；保留第一版全部回归测试。
- 执行编译、仓库静态检查和 HALF／IRFEL GUI 冒烟检查。真实运行验收限定于虚拟 IOC：分别调整四极铁和校正铁，验证光学／轨道变化、基线差值、恢复结果及其他应用的设定显示一致性。

默认保持手动 `Apply`；自动计算滑块、RF 编辑、扫描、完整工作点恢复和持久化保存不纳入本版。
