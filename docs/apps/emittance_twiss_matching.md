# Emittance Twiss Matching v1

`emittance → Matching` 根据同一运行状态下的双平面实测 Twiss，生成四极铁 K1 建议，并保存执行后的复测对比。计算和导出不写 PV；新增 Apply suggested K1 和 Restore previous K1 按钮可显式写入当前后端的 K1。能量按钮保持不变。

## 使用流程

1. 选择完整模型线路。可载入扫描 `metadata.json`、多屏测量 JSON，使用当前窗口的 Latest scan / Multi-Screen result，或手动填写参数。界面发射度单位为 **几何 mm·mrad**，内部为 m·rad；能量为参考点的**动能 MeV**。
2. 确认参考元件与入口／出口。四极扫描导入到扫描四极铁入口，多屏重建导入到其参考元件出口。两平面必须对应同一次运行状态。
3. 提供计算路径上所有四极铁的基线 K1。历史扫描通常只保存扫描段快照，缺少的位置保持空白。可以导入模型快照，或明确点击 Read current K1 snapshot 读取当前控制系统；当前快照不会自动被认定为历史状态。允许在表格中手动补充值，需勾选状态一致声明。
4. 选择目标及其入口／出口，并勾选可调四极铁。QL07–QL12、QT01–QT06 便捷组选择全部六台，目标设为最后一台出口；测量位置保持不变。目标入口之前的全部可调磁铁才能影响该目标。
5. 为每台可调磁铁填写 K1 下限、上限和最大绝对改变量。仅明确配置的 K1 设备限制可预填；扫描范围不作为设备范围。可选填 X/Y 最大 RMS 包络；空白表示未约束。
6. Calculate suggestion。显示当前／设计／候选双平面 β、α、RMS 曲线和 K1 表。默认模型容差为两平面 `Bmag - 1 <= 0.01`，可修改。响应不足四个独立自由度或违反约束的结果不标为可用建议。
7. Save JSON 保留完整诊断，Export K1 CSV 导出有效建议。可点击 Apply suggested K1 应用，或通过现有控制系统手动执行，保持能量按钮设置不变。
8. 载入复测 JSON，或在左侧输入复测参数，填写**实际执行后的** K1 快照，重新声明状态一致，然后 Compare edited inputs。复测可以位于不同测量点；传输至目标的结果明确标为复测推算。修改左侧输入后，原建议变为过期，但仍可作为历史预测参与复测比较。

JSON 自动保存到当前 machine/backend 的 `runtime/.../runs/matching_<timestamp>/matching.json`，包括测量、声明、快照、模型内容和指纹、限制、入射边界、设计／当前／候选曲线、求解诊断与复测。重新打开历史建议可查看，但需重新计算才能导出 K1。

## 应用与恢复

- **Apply suggested K1**：写入当前窗口显示的 machine/backend，沿用 emittance 的写权限。只有未过期且可用的计算结果可以应用；历史归档必须重新计算。
- 应用前检查路径上四极铁 K1 与计算基线一致，再读取并保存全部可调磁铁的原始 K1。按照线路顺序逐台写入，每次写入前记录尝试，等待写入完成并核对 K1 PV 数值（相对／绝对容差 `1e-6`，验证超时 5 秒）。这里验证的是 K1 PV，不代表电源电流已经稳定或束流已经达到目标。
- 不做额外能量归一化；只支持模型快照与可写 K1 使用同一 PV、直接转换的映射。保留求解范围与已配置设备范围检查。
- **Restore previous K1**：按相反顺序恢复最近一次应用前的原始 K1，包括写入超时、结果不确定的磁铁。仅恢复尝试写入的磁铁，不修改其他元件或能量。失败项可以再次点击恢复重试。
- 不完整的应用需先恢复，才能执行新的建议。成功应用后的下一次新建议会建立新的恢复基线，旧记录仍归档保留。
- 操作在后台执行；Cancel 可中断后续步骤。取消或失败不会自动再写一轮恢复值，恢复按钮保留原值供显式操作。应用、恢复后建议标为过期，需复测／重新计算。
- 原值与每一步结果保存到 `runs/matching_execution_<id>/execution.json`，当前恢复记录保存在同一后端目录的 `matching_execution_latest.json`。重启窗口可继续恢复；机器、后端或 PV 映射不一致时拒绝自动恢复。

## 物理约定

- 使用测量点能量和模型中的 RF 电压、相位，以 `ΔE [MeV] = VOLT / 1e6 × sin(PHASE)` 累计能量。重复出现的同名腔按线路出现次数累计。
- 控制系统 K1 已按实际能量归一化，程序不再次缩放 K1。修改能量按钮会保持 K1 并调整电流，本功能不操作能量按钮。
- 首先以测量时的 K1 和模型 RF 参数，将测量传输到第一台可调磁铁入口。随后入射 Twiss 和能量固定，求解器只改变选中的 K1。
- 设计 α、β 来自未覆盖当前快照的固定设计 lattice。设计 RMS 曲线使用实测归一化发射度，以便比较包络；不代表设计发射度目标。
- 跨加速段根据动量比更新几何发射度。正反传输使用完整前向矩阵或其逆矩阵，参考位置相同则使用单位矩阵。
- 最大 RMS 检查覆盖元件边界以及硬边四极铁内部的解析 β 极值。漂移内 β 为凸函数，最大值在边界；RF 和其他元件内部的极值不作完整认证。该包络约束不是孔径或损失保护。
- 仅使用普通双平面线性光学。不自动补偿耦合、色散、尾场、空间电荷或轨道误差；模型中这些效应不能由 Twiss 匹配结果认证。

模型求解状态为“模型满足目标”“模型改善但未达标”“无可用建议”。有限预算内可能无法找到解。复测显示前后 Twiss、发射度、失配改善、预测误差以及执行 K1 与建议值之差；没有不确定度时不宣称统计显著改善。

复测必须具有相同 machine/backend/line 和模型指纹，并提供所需执行后快照。目标点能量与原预测不一致时（相对或绝对 MeV 容差 `1e-6`），要求针对新能量重新匹配，而不输出通过结论。用户复测容差独立于模型求解容差，默认同为 0.01；它不代表真机传输验收标准。

## 实现与验证

- `matching.py`：与 Qt、EPICS 无关的数据接口、固定边界求解、复测及 JSON/CSV 归档。
- `matching_model.py`：Elegant 适配、模型指纹、位置／能量传输和包络采样。
- `matching_import.py`、`matching_workspace.py`：测量格式适配和界面。主入口仅接入工作区及关闭时的取消处理。
- 取消在当前模型调用结束后生效；窗口关闭时不销毁仍运行的计算线程。

在 `half_linac` 环境执行：

```sh
python -m unittest discover -s tests -p 'test_emittance_matching*.py' -v
python scripts/check_emittance_matching.py
bash scripts/check.sh
```

第二条命令要求 PATH 中有 elegant，使用 `/tmp` 隔离目录进行 QL、QT 和跨 RF 短时计算，不启动 IOC/VM 或访问 PV。GUI 测试使用 offscreen 插件，并禁止自动 PV 读写。

## 测量链离线诊断

`scripts/diagnose_emittance_measurement.py --scan-dir <扫描归档> --matching <matching.json> --output <临时目录>`
使用当前 HALF VM 的束流发生器与归档 K1 基线，在独立目录追踪到扫描四极铁入口，再以局部线性矩阵扫描，比较粒子 RMS、像素图像高斯拟合和图像 RMS 的反演结果。当前 VM 的非 K1 配置并非历史快照，因此这是偏差复现实验，不是原扫描的精确重建；也不是完整非线性扫描验收。

2026-09-12 QT02/PRF07 归档的回放中，粒子 RMS 正确恢复入口 X β=102.44 m，而图像高斯拟合恢复为 77.11 m，接近归档的 76.06 m。测量链偏差仍需进一步处理；不能据此报告 VM 匹配完成。

扫描重算现兼容旧 `%.6e` K1 文件与完整精度质量记录，新文件保存完整浮点精度。质量自适应模式至少需要五个不同的合格 K1 点，不足时不输出有效拟合，避免三个点精确拟合造成虚假的低残差。

## 独立完整线路验证

```sh
python scripts/validate_matching_independent.py --output /tmp/matching_validation
```

该脚本不访问 PV、不改运行中的 VM。它在设计线路中主动扰动一个四极铁，直接读取独立完整线路 Elegant 输出作为测量输入，求解后把建议 K1 写入另一份临时线路，再运行 Elegant 验收。测量和验收参考不由 matching 的传输接口生成。每个场景保存设计、扰动、执行后的 JSON/lattice/Elegant 输入输出，以及 matching 输入、候选值和数值报告。

覆盖 QL07～QL12（QT02 入口测量、QL12 出口目标）、QT01～QT06（QT06 出口测量和目标）、跨 RF（QT02 出口测量、QT01 入口目标）。正例要求独立目标 Bmag−1≤1e-4、预测与独立输出失配≤1e-6，并检查反推入射条件。另用 20000 个小发射度、零能散、零电荷粒子检查线性极限下的实际跟踪。`--case` 可单独选择场景。

`biased_input` 反例主动将输入两平面的 β、α 乘以 0.75，检查即使模型满足目标，独立执行结果也未达到 0.01 容差，且载入独立复测后不报告通过。这些测试验证模型匹配与参考位置处理，不证明有限电荷、能散、成像测宽或控制系统执行时序已经满足要求。

2026-09-13 独立验证的正例结果（X/Y）：

| 场景 | 调整前 Bmag | 执行建议后独立 Bmag−1 最大值 | 粒子跟踪 Bmag−1 最大值 |
| --- | --- | --- | --- |
| QL | 1.05948 / 1.05489 | 1.2e-9 | 1.9e-9 |
| QT | 1.11738 / 1.06197 | 9.2e-11 | 6.9e-8 |
| 跨 RF | 1.05948 / 1.05489 | 1.2e-9 | 7.8e-8 |

预测 β 与独立完整线路的相对差最大约 1.6e-6。偏置输入反例中，模型预测 Bmag 接近 1，而独立执行后为 1.04158 / 1.04165，说明求解器满足模型目标不能替代测量准确性验证。
