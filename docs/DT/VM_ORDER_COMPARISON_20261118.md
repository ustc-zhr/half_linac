# HALF VM 同阶对照验收

2026-11-18，使用已冻结的 HALF VM 工作点完成同阶对照。**现有一阶矩阵预测与一阶粒子跟踪在舍入误差量级一致；此前 0.001467% 的最大相对束宽残差由三阶和一阶输运的区别复现，且以动量散布参与的高阶效应为主。** 本工作点的一阶计算通过现有 `1e-6 mm` 数值一致性标准。

本次运行全部在独立离线目录完成，仅新增运行产物和文档。原归档、当前 VM 输入和 workbench 文件哈希不变，PV 访问尝试为 0，产品代码、调束状态机和 EPICS 写入机制保持不变。

## 同一入口与原结果复现

源工作点与 [入口对齐验收](VM_ENTRANCE_ALIGNMENT_20261117.md) 相同：VM session `51274a68dc5f4632845523ffcdb2f1cc`，calculation 1，input version `51dcdf3962950513a01e2b7fd3fd62eba1db14fd63014ba75c8fa53ee39917c4`。

完整 VM 重放使用冻结的运行输入、相同 ELEGANT 可执行文件和随机种子，唯一输入变更是在 QT02 前增加一个坐标 WATCH，输出 `qt02_entrance.out`。所需两份尾场文件从仓库复制到离线目录并记录哈希。重放后 PRF06 的 x、xp、y、yp、p 按 particleID 对齐，与原粒子输出逐值完全相同，证明新增记录点及离线运行没有改变该工作点结果。

QT02 入口输出包含 8768 个粒子，pCentral = 4298.404874854445 mc，参考动能为 2195.969438216034 MeV，原相对动量散布为 0.288361%。从入口粒子读取的总体协方差（ddof=0）与上次从 DMTB 出口 `one.sig` 提取的入口协方差一致，未使用 PRF06 拟合入口。

随后仅对 **QT02 → DMTC1 → PRF06** 做四组局部跟踪。两种阶次使用完全相同的入口文件；零动量散布对照只把每个粒子的 p 改为 pCentral，其余列和粒子 ID 保持不变，横向协方差保持不变。

## 束宽与阶次比较

束宽和残差单位均为 mm，残差定义为粒子跟踪减一阶矩阵预测。

| 计算 | X RMS | Y RMS | X 残差 | Y 残差 |
| --- | ---: | ---: | ---: | ---: |
| 一阶矩阵预测 | 0.4685821480739855 | 0.10377205223907715 | — | — |
| 一阶跟踪，原动量散布 | 0.4685821480739856 | 0.10377205223907714 | 5.55e-17 | -1.39e-17 |
| 三阶跟踪，原动量散布 | 0.4685823769883007 | 0.10377052990015127 | 2.28914315e-7 | -1.52233893e-6 |
| 一阶跟踪，零动量散布 | 0.4685821480739856 | 0.10377205223907714 | 5.55e-17 | -1.39e-17 |
| 三阶跟踪，零动量散布 | 0.4685821473867314 | 0.10377205235090854 | -6.87254142e-10 | 1.11831391e-10 |

局部三阶跟踪的 X、Y RMS 均与原完整 VM 结果完全相同；与完整重放的最大横向粒子坐标差小于 2.2e-19 SI。由此把问题限制到了同一局部段的输运阶次，而非入口来源、元件参考面或 PV/模型参数映射。

将原动量散布置零后，三阶与一阶束宽差缩小至约 1e-10 mm。有限动量散布对阶次差异的对照量为：

```text
Δ = (三阶原散布 − 一阶原散布) − (三阶零散布 − 一阶零散布)
X:  2.29601569e-7 mm
Y: -1.52245076e-6 mm
```

这说明本工作点原残差主要与有限动量散布参与的高阶输运有关。该对照量包含动量与横向坐标的交叉作用，没有把残差分解为相互独立、可直接相加的具体色差系数。

## 产物与复验

完整本地产物位于 [runs/digital_shadow_order_comparison/20261118_qt02](../../runs/digital_shadow_order_comparison/20261118_qt02/)，受既有 runs 忽略规则排除：

- `tolerances.json`、`verification.json`：计算前容差及附加逐粒子、源码哈希核对。
- `full_replay/`：完整输入、QT02 入口粒子、屏幕输出及 ELEGANT 日志。
- `local/order1_original_dp/`、`local/order3_original_dp/`：同一实际入口分布的一阶和三阶输运。
- `local/order1_mono/`、`local/order3_mono/`：仅替换粒子动量的零散布对照。
- `order_check.py`、`SHA256SUMS`：实际执行脚本和完整产物校验清单。

在专用工作区、现有 half_linac 环境中可离线复验；输出必须使用新目录。脚本验证冻结源归档和 ELEGANT 哈希，不需要启动 IOC 或 VM：

```bash
source scripts/setup.sh
python3 runs/digital_shadow_order_comparison/20261118_qt02/order_check.py \
  --repo "$PWD" \
  --source runs/digital_shadow_vm_alignment/20261117_qt02 \
  --output runs/digital_shadow_order_comparison/recheck
```

本结论限定于同一 ELEGANT 引擎、同一入口分布和一个直线四极铁局部段，没有验证实机诊断精度、RF/弯转段或其他工作点的模型适用范围。
